How this works, and how accurate it is

The formula

iRacing scores safety as Corners Per Incident (CPI). The displayed SR is a mapping of that hidden CPI:

SR = band + 1.5236 · ln( CPI / (3.4949 · 1.4562^(class_index + band)) )

This was fitted to 12,639 real (SR, CPI, licence level) observations taken from iRacing's own results data, and reproduces iRacing's displayed SR to MAE 0.0099 held out on 123,361 later sessions. That is the error of this mapping alone; the end-to-end prediction error is larger — see “How well it holds up” below. The band floors form a single geometric ladder, which is why C@3.00 = B@2.00 = A@1.00 = 22.9 CPI.

Why crossing 2.00 or 3.00 jumps

iRacing documents “an additional 0.40 Safety Rating” when you cross a whole number. That is not a bonus bolted on — it falls out of the overlapping bands above. The exact value is 1 − a·ln(r) = 0.427; iRacing rounds it to 0.40 in its help article. The same geometry explains why a class promotion costs almost exactly 1.00 SR.

How one session moves your CPI

Your accumulated CPI is an exponentially weighted moving average over corners. A session of c corners carries weight

alpha  = 1 - exp(-c / window)
window = 1060 x √2^(band-1) x class factor

All of this was measured, not assumed. Within Class C, B, A and Pro the window depends only on the SR band, not on the class — at band 3 the medians are C 2451, B 2342, A 2448 corners. Rookie and Class D are genuinely shorter, so new drivers' SR moves faster.

Why your number may differ slightly

The largest remaining error is not the algorithm — it is lap counting. Results pages report whole laps, while iRacing scores the distance you actually drove: the part-lap past the line, the run to the checkered, the out-lap. On a road course that is worth roughly half a lap to a lap.

So if you are checking this calculator against a past result, add about half a lap on a road course and it will line up. The desktop overlay does not have this problem at all — it measures distance directly.

Practice sessions only count when they are part of a Ranked race event. Standalone Open Practice does not affect SR at all.
